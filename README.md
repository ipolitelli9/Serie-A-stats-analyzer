# Serie A Stats Analyzer

A Python-based analysis tool for processing Italian Serie A match results, calculating standings, and retrieving team-specific performance metrics.

## Features

* **Points Calculation**: Computes total points for any team in the dataset based on match outcomes.
* **Team Statistics**: Tracks total wins, draws, and losses for a selected team.
* **League Standings**: Generates the complete league table dynamically.
* **Interactive CLI**: Menu-driven command-line interface to query team data interactively.

## How to Run

1. Ensure you have **Python 3.x** installed.
2. Clone this repository:
   git clone https://github.com/ipolitelli9/Serie-A-stats-analyzer.git
3. Run the script:
   python main.py

## Project Structure

* `main.py`: Contains match dataset, statistical functions, and interactive terminal interface.
* `README.md`: Project documentation.
